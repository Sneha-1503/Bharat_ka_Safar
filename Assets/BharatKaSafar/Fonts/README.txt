Bharat Ka Safar - Font Collection

Yatra One Regular: game title and chapter headings.
Fraunces SemiBold: vintage watercolor buttons and headings.
Cinzel Bold: royal title alternative.
Kalam Bold: travel diary tips and short messages.
Mukta SemiBold: menu labels and buttons.
Mukta Regular: body text and instructions.

Official source: https://github.com/google/fonts/tree/main/ofl
Each family folder includes its SIL Open Font License (OFL.txt).
Fraunces and Cinzel have been instantiated as static fonts for Unity. Original variable sources are preserved under output/font-sources.

Unity: use these TTF files in Text components, or create TextMeshPro Font Assets from the desired font via its context menu. No scenes, prefabs or existing labels were changed. Text baked into existing button PNGs is unchanged.
